# מדריך מהיר: יצירת קליפים עם GPU חינמי (Kaggle)

(קובץ הוראות ליוצר בלבד. כל התוצרים של הפרויקט נשארים באנגלית.)

מה זה עושה: לוקחים תמונות מאושרות (פריימים מ-Canva), ו"מחיים" כל אחת ל-4-5 שניות וידאו. הכל בחינם, על כרטיס מסך של Kaggle.

## פעם אחת: הכנות
1. היכנס ל-kaggle.com והירשם עם מייל של הסטודיו (לא האישי).
2. לחץ על תמונת הפרופיל, אחר כך Settings, ואז Phone verification. הכנס מספר טלפון וקוד שמגיע בהודעה. בלי זה אין GPU ואין אינטרנט במחברת.

## בכל הרצה
1. קבל מהמהנדס (או מ-Claude) את הקובץ `gpu_input.zip` (תמונות + רשימת הקליפים) ואת `dumpling_clips.ipynb`.
2. ב-Kaggle: Create, ואז New Dataset. גרור את `gpu_input.zip`, קרא לו `dumpling-input`, השאר Private, ולחץ Create.
3. Create, ואז New Notebook. בתפריט File בחר Import Notebook והעלה את `dumpling_clips.ipynb`.
4. בצד ימין: Add Input, ואז Your Datasets, ובחר `dumpling-input`.
5. בצד ימין תחת Session options:
   - Accelerator: **GPU T4 x2**
   - Internet: **On**
6. בדיקה ראשונה (מומלץ, כ-3 דקות): בתא הראשון שנה `SMOKE_TEST = False` ל-`SMOKE_TEST = True`, לחץ Run All, וחכה שיופיע קליפ קצר. אחרי זה החזר ל-False.
7. הרצה אמיתית: לחץ **Save Version**, בחר **Save & Run All (Commit)**, ואפשר לסגור את הדפדפן. המחברת רצה ברקע.
8. כשהסתיים: היכנס לדף המחברת, לשונית **Output**, והורד את **`dumpling_clips.zip`**.
9. שלח את הקובץ הזה למהנדס. הוא ישלב אותו בפרק עם קול, מוזיקה וכתוביות.

## כמה זמן וכמה זה עולה
- עלות: 0. Kaggle נותן כ-30 שעות GPU בשבוע (המספר המדויק מופיע בחשבון שלך).
- קליפ אחד של 5 שניות: בערך 4-8 דקות (הערכה, לא נמדד). שני קליפים במקביל על שני הכרטיסים.
- פרק שלם (כ-30 קליפים, 2 ניסיונות לכל אחד): בערך 3-4 שעות על T4 x2. זה בערך עשירית עד רבע מהמכסה השבועית.
- בהרצה הראשונה בכל פעם מורידים את המודל (כ-14GB, 10-20 דקות).

## אם משהו לא עובד
- "NO GPU FOUND": לא הדלקת GPU בצד ימין. הדלק, הפעל מחדש, והרץ שוב.
- שגיאת הורדה: Internet לא דלוק (או שלא אימתת טלפון).
- קליפים שחורים: שנה `DTYPE = "auto"` ל-`DTYPE = "bf16"`.
- אפשר לעצור וגם להריץ שוב בכל רגע. קליפים שכבר נוצרו לא נוצרים מחדש.
- אם אין Kaggle: אותו קובץ עובד ב-Google Colab (colab.research.google.com, אחר כך File, Upload notebook, ו-Runtime, Change runtime type, T4 GPU). הוא יבקש להעלות את ה-zip.
