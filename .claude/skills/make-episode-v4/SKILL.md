# Make an episode (v4.5 pipeline: voice first, gates before GPU)

Read first: `CLAUDE.md`, `production/v4/PRODUCTION-BIBLE.md` (FORMAT CHANGE: ~1-MINUTE EPISODES and the v4.4 DIRECTIVES), `production/v4/shot-rules.md`, `production/v4/fix-plan.md` (Fix 1-7), `tools/episode_maker/gpu/README.md`, `production/v4/motion-tech.md`, `production/v4/voice-tech.md`.

1. **Shot list:** `scripts/episode-NN-v4.5.md` via the `write-episode-script` skill (20-26 AI clips of 2-3.5 s, about 1:00, hard max 1:15). Gate: `python3 tools/episode_maker/paper/lint_shotlist.py <script>` -> `RESULT: PASS` (`--json` gives the parsed clips for the builders).
2. **Voices first, at natural speed:** Qwen3-TTS VoiceDesign (`tts` task), 2-3 takes per line, pick by delivery and timing. No `voice_speed` in the spec; if the cut is long, cut words in the script and re-lint.
3. **Word timestamps** for every picked take (forced alignment on CPU, e.g. openai-whisper word timestamps), saved next to the WAVs.
4. **Animatic = the edit decision list:** build the spec from the voices (each clip's length = its line + reaction beat; gag action times on the words), render `-animatic` from START stills (placeholders before stills exist). Creator gate on the animatic.
5. **Stills (GPU, `images` task, backend `klein`):** references = only the clean single-character sheets of the visible faces (never the old multi-character scene refs) + at most one empty background plate; the prompt states the head count; END = `@START` + "Same image. Change only: ...". Portrait first; 2 variants. **Stills gate:** `python3 tools/episode_maker/qc_stills.py specs/frames/<ep> --script <script> --sheet out/qc_stills.png` + look at the contact sheet; re-roll DUP / TEXT / SOFT stills before any video job.
6. **Clips (GPU, `clips` task, backend `ltx98d`):** each clip at its animatic length + 0.3 s handle (8-frame step), keyframes at the action times. **Prompt compiler rules:** prompt = "Static camera, fixed framing." + "Exactly N people: ..." + ACTION with facial beats + mouth phrase ("mouth gently closed, not talking" for closed/overlay, "talking naturally" for lipsync) + style + negative; never PEAK, cut, insert, edit:, snap zoom, whip, [CARD, badge, title, text, frames (re-lint the compiled prompts); motion from the shot list (low for talk shots, high max 3); talk close-ups at 576x1024. KNOWN BUG: RIFE corrupts every 2nd frame (set post.rife 0, or drop frames on install only when the clip is really 24 fps; check fps first).
7. **Clip QC gate:** `cd tools/episode_maker && python3 qc_clips.py specs/clips/<ep> --frames specs/frames/<ep> --script ../../scripts/<script> --spec specs/<spec>.json --md out/qc.md` (exit 1 on any FAIL). DUP?, DUP_IN_STILL?, MORPH_RISK, FACE_SMEAR, JUMP, TEXT, STRIPES, SPEED must be 0, and TRUNC, SLOWMO, FREEZE must be 0 in the edit. Re-roll failed ids with seed + 1 (max 2), then restage. Log GPU minutes in `production/v4/gpu-ledger.md`; stop and re-plan at 22 GPU-h in a week.
8. **Mouths and edit:** `mouth_overlay.py` (Rhubarb cues + per-character sprites, tracked by `mouth_track.py`) on every `overlay` row, LatentSync on `lipsync` rows; EDIT-column effects, cards, captions (safe band), camera moves on ones, all in `make_episode.py`; AI clips play at 1:1 (no stretch below 0.95x, no trim past the clip end). Mix -14 LUFS / -1 dBTP.
9. **Render** both orientations: `python3 make_episode.py specs/<spec>.json out/<name>.mp4 --both`; mobile files with ffmpeg at about 780 kbps (720x1280 / 1280x720, under 20 MB).
10. **QA before sending:** duration <= 1:15, `qc_clips.py` clean, contact sheet (Read tool) for duplicates, smears, text and captions over faces/hands/food, audio levels, loop the Short 3 times. Then send both mobile files to the creator in chat. Never upload or publish.
