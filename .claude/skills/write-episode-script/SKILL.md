# Write an episode script (v4.5 shot-list format)

Read first: `CLAUDE.md`, `production/v4/PRODUCTION-BIBLE.md` (the FORMAT CHANGE: ~1-MINUTE EPISODES section overrides older lengths), `production/v4/shot-rules.md`, `production/v4/comedy-style.md`, `production/season-map.md` (dumpling, place, Dad's clue), and the reference `scripts/episode-01-v4.5.md` (copy its structure and table header exactly). `scripts/episode-01-v4.4.md` is the old 2:29 extended cut, not the template.

1. **Story in the 60-s structure:** hook 0-3 s (the funniest or most surprising image) -> title hit <= 2 s (no separate opening) -> host + place -> one learning beat (1-2 sourced facts, said once, plainly) -> central gag / lesson -> legend in ONE scroll beat <= 8 s ("Legend says") -> Dad heart beat (no jokes) -> next-episode hook + "Dad was right..." (last spoken line). "For dumpling research!" at least once. Jokes only on the Uncle's behavior, never his weight, a country or a people. Every 3rd episode: a 20-25 s recipe segment with grown-up-step badges, doneness temps (71 C / 160 F pork, 74 C / 165 F chicken) and the allergy line.
2. **Write lines for natural voice speed** (Boy about 2.4, Grandma 2.3, Uncle 2.0, Narrator 1.9 words/s; no speed-up later). A line must fit one 2-3.5 s clip; longer thoughts continue as an `off`/`V.O.` line over a reaction or macro clip. If it runs long, cut words.
3. **Design every AI clip by the shot rules:** max 2 visible faces (a third only as hands/back, unnamed in the prompt); talk shots CU/MCU with the speaker's face >= 25%, one speaker per clip, shot / reverse shot for banter; wides carry no on-screen dialogue; one action per clip; END = "Same framing ...; change only: ..."; no text, cards, signs, camera moves or edit words in START/END/ACTION; risky types (flying, levitation, morphs, entering/leaving, crowds, eating with the face covered) become CODE effects or `HERO` rows.
4. **Fill the table** (one row per clip): `Clip | Dur | Start | Method | Faces | Shot | START keyframe | END keyframe | ACTION | VOICE | Mouth | Motion | EDIT | SFX | Caption`. Faces = `N: Names (+hands: X)`; Shot = `CU · face 40%`; VOICE = `SPEAKER (on|off|V.O.) [delivery]: “words”`; Mouth = closed/overlay/lipsync; Motion = low (all talk shots) / medium / high (max 3); EDIT = cards, badge, title, place name, auras, sweat drops, speed lines, impact frames, camera moves, Narrator gong + scroll edge; Caption = TOP/BOTTOM band that never covers faces, hands or the dumpling.
5. **Lint until it passes:** `python3 tools/episode_maker/paper/lint_shotlist.py scripts/episode-NN-v4.5.md` must end with `RESULT: PASS`; paste the summary line into the script's Numbers section. Read the WARNs (tight lines, multi-action wording).
6. Add a laugh map (>= 2 laughs per 15 s, except the Dad beat), fact-landing check, safety checks, a restore list (what was cut, with seconds), upload details (title options, description with the page link first, pinned comment) and Sources with real URLs (every fact checked in 2 sources; "Legend says / Many people believe" when unproven).
7. Write a Hebrew reading copy for the creator in the scratchpad (never in the repo). Anonymity: no personal names or emails. Commit and push.
