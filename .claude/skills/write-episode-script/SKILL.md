# Write an episode script

1. Read `CLAUDE.md`, `production/series-format.md`, `production/season-map.md` (find the episode number, dumpling, place, cooking method, Dad's clue), `production/character-bible.md`, and `scripts/episode-01-xiaolongbao.md` (the structure to copy).
2. Write `scripts/episode-NN-<dumpling>-<place>.md` with: Length line, m:ss timed beats (hook in the first 3 s, arrival with sights and sounds, Uncle gag with escalation, a "Legend says..." history beat, a fun-fact card, Dad's wisdom, a quiet heart moment, a cliffhanger into the next episode), dialogue at most ~3 words per second, upload details (title, description with the page link in the first line, pinned comment), and a Sources section with real URLs.
3. Every 3rd episode of a country arc is Recipe + Recap: fast recipe montage with grown-up-step badges, doneness temps, allergy line, substitutes, a recap card (dumpling, country, history, secret, how to eat, Dad's clue), the map stamp, and a "Full recipe (for description)" section.
4. Verify every fact with at least two sources (WebSearch); use "Legend says / Many people believe" when unproven. Jokes only on the Uncle. Keep canon: journal clues numbered in order (see season-map), Dad never shown, ending line "Dad was right...".
5. Anonymity: never include the creator's personal name. Commit and push.
