## How to read the shot list
- **Method:** `AI` = image-to-video with START + END keyframes, fixed camera, 2.0-3.5 s, one action. `CODE` = built in code (paper-cut, title, effects); not sent to the video model. `HERO` = paid model or code effect only (none in this cut).
- **Faces:** the exact number and names of characters whose faces are visible. `(+hands: X)` / `(+back: X)` = X appears only as hands or from behind and is **never named or given a face in the prompt** (the prompt says "an old woman's hand, only the hand is visible").
- **Shot:** ECU, CU, MCU, MS, MWS, WS, MACRO, with the speaking face's height in % of the picture height for talk shots (>= 25%).
- **START / END / ACTION** are the only fields that go into the stills and video prompts. END always starts "Same framing ... change only:".
- **VOICE:** `SPEAKER (on|off|V.O.) [delivery]: “words”`. `on` = the speaker's face is on screen and gets mouth animation; `off` = in the scene but not on screen (the visible face listens, mouth closed); `V.O.` = narration. One speaker per clip.
- **Mouth:** `closed` (prompt says "mouth gently closed, not talking"), `overlay` (prompt says mouth closed; sprite flaps added by `mouth_overlay.py` from Rhubarb cues), `lipsync` (prompt says "talking naturally"; LatentSync pass). **Motion:** `low` for every talk shot, `medium` default, `high` at most 3 per episode.
- **EDIT:** everything done in `make_episode.py` on top of the clip: cards, badge, title, place name, auras, sweat drops, star eyes, speed lines, impact frames, camera moves (digital push / punch-in / bump / shake, always on ones), Narrator gong + 0.4 s scroll-edge wipe, transitions, grade.
- **Caption:** the free band for captions (TOP: 9:16 y 260-430; BOTTOM: 9:16 y 1260-1440, inside the safe box of quality-research H1); cards use the other band.
